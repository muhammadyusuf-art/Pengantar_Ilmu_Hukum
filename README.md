# Media Pembelajaran Interaktif: Struktur Pengadilan Pidana

Aplikasi web pembelajaran bertahap untuk mata kuliah **Pengantar Ilmu Hukum (Semester 1)** yang membahas peran, kewenangan, dasar hukum (KUHAP), dan tata letak posisi duduk 6 aktor utama di dalam sidang pidana:
1. Hakim
2. Jaksa Penuntut Umum
3. Penasihat Hukum (Advokat)
4. Panitera
5. Terdakwa
6. Saksi

## Cara Menjalankan
Cukup buka file `index.html` melalui peramban (browser) apa pun, atau akses langsung melalui tautan **GitHub Pages** setelah diunggah ke repositori.
